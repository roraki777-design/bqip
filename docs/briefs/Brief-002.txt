============================================================

15. CANONICAL BOOK SYNC ALGORITHM
============================================================

Freeze the current documented USDⓈ-M algorithm.

STATE:

EMPTY
BUFFERING
SNAPSHOT_REQUIRED
BRIDGING
HEALTHY
DEGRADED
RESYNC_REQUIRED

Algorithm:

A. Begin buffering WebSocket diff-depth events.

B. Obtain REST depth snapshot.

C. Let S = snapshot.lastUpdateId.

D. Drop buffered events where:

u < S

E. Find the first remaining event satisfying:

U <= S
AND
u >= S

If no event bridges S:

snapshot cannot yet be connected to the buffered stream.

Retry according to future recovery policy.

F. Initialize local book from snapshot.

G. Apply the bridge event.

H. For every subsequent applied depth event:

current.pu MUST equal previous.u.

If:

current.pu != previous.u

then:

DO NOT continue publishing a trusted canonical book.

Emit:

VENUE_GAP or appropriate documented continuity cause

Book state:

DEGRADED

and require:

RESYNC_REQUIRED.

I. For each bid/ask update:

quantity > 0:
replace the absolute quantity for that price.

quantity == 0:
remove the price.

Do not add quantities.

Do not subtract quantities.
